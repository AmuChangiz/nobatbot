# ⚠️ پوشه خطر

## reset.bat — factory reset

**همه داده‌های دیتابیس + لاگ‌ها** پاک می‌شوند. فقط **`.env`** روی دیسک می‌ماند.

مناسب برای:
- تحویل ربات به دکتر دیگر
- شروع تست از صفر (بعد از تست دوستان)

بعد از reset:
1. `.env` را ویرایش کن (`BOT_TOKEN`, `SUPERADMIN_IDS`, ...)
2. `start.bat` را بزن
3. از `/admin` تخصص، پزشک و برنامه تعریف کن

تأیید: تایپ `RESET`
